# 多页动画：用多张 PPT 做出动画效果

> 配套 `teach-replay` 技能 §7.6。目的：在你的 .pptx 里加不了可靠内建动画的前提下，用**连续多页**做出课堂需要的「一步一步出现」，且任何播放器（PowerPoint / WPS / 希沃白板 / 导出 PDF / 打印讲义）都不丢效果。

## 1. 为什么不用内建动画

| 问题 | 后果 |
|---|---|
| 不同播放器对动画的解释不同 | 学校电脑放出来和你的电脑不一样，甚至不动 |
| 导出 PDF / 发讲义时动画全部丢失 | 学生课后拿到的版本只剩最后一帧，看不懂过程 |
| 动画多、设置烦，容易被误触 | 上课时点错、动画乱飞，教师不敢用 |
| 依赖"自动播放" | 讲稿节奏被动画牵着走，提问等待时间不够 |

结论：**把"过程"做成页**。每页是一个可独立阅读的静态帧，翻页就是"播动画"。

## 2. 版式规范（让"变化"可被看见）

1. **元素位置锁定**：同一组序列里，主图形的位置、大小、配色、投影角度完全不变，只允许新增或替换某一处元素。
2. **新增即高亮**：新增元素用对比色（如橙/红），上页已有的元素保持原色或降为浅灰。
3. **页脚带序列标识**：`原理组 2/4`、`反例组 1/3`，方便课堂按页翻、也方便学生记笔记。
4. **一页一个信息点**：标题可不变，正文只多一条；超过两条就说明该拆页。
5. **左侧/右侧留结论区**：结论区始终留白，等学生说出来再在下一页落下文字（不要提前写）。
6. **小图定位**：放大页左下角保留整图缩略，学生知道"这是哪一块"。

## 3. 七种手法与写法

### 3.1 拆页序列（首选）
把认知过程拆成 2–4 帧，每帧多一个元素。

```
P1  两个三角形并排（无标注）
P2  + 拼接点红圈
P3  + 6 个角的编号 1–6
P4  + 周角弧线 + "= 360°"
P5  + 结论文本「拼接点周围各角和 = 360°」
```
每页备注写清「本页新增什么、什么时候翻」。

### 3.2 同位置替换
版式完全不动，只换内容，制造"同一位置发生变化"的对比感。

```
P1  三个正五边形，角标 108°、108°、108°
P2  同位置，三块之间出现 36° 缺口（红色扇形）
P3  同位置，结论「324° < 360°，差 36°」
```

### 3.3 叠层遮罩
结论先用与背景同色的块盖住，后一页去掉块。

```
P1  总结页骨架 + 三块灰色遮罩（只露标题）
P2  揭开第一块「两个条件」
P3  揭开第二块「三类图形」
P4  揭开第三块「360°」
```
> 遮罩色必须与背景完全一致；不要用半透明，投影仪会显示成灰块。

### 3.4 对比翻转
两页同版式不同内容，来回切 = 对比。

```
P1  铺法 A（有缝）：红色标出缝隙
P2  铺法 B（合格）：绿色打勾
P3  铺法 C（既缝又压边）：两处同时标红
```
讲法："我们来回看这两张——差在哪？"

### 3.5 聚光灯放大
整图页 → 局部放大页（保留小图定位）。

```
P1  整面铺砖（小图）
P2  同一图局部放大到 6 个三角形共顶点，其他区域淡出
P3  放大到"拼接点"一个点 + 角度标注
```

### 3.6 路径页
同一条数轴/流程/地图，高亮点逐页前移。

```
P1  数轴 0—1，分段，无标注
P2  第一段 1/2 高亮
P3  第二段 1/4 高亮
P4  剩余 1/4 高亮 → 结论
```

### 3.7 转场语言
- 硬切：强调"这是另一件事"（反例、对比）。
- 叠化：同一过程继续（拆页序列内部）。
- 推进/擦除：有方向的过程（时间线、步骤）。
- 统一一种主转场，全片别超过两种；不要旋转、3D、闪烁。

## 4. 写出动画序列表（进 06 文件与教案附录）

| 组名 | 页号 | 本页只新增什么 | 讲稿卡点（说什么才翻） | 切换方式 | 对应原片/替换说明 |
|---|---|---|---|---|---|
| 原理组 | P13 | 红点（指认对象） | 学生说出"周围这些角"后翻 | 硬切 | 原片 [24:44]，示例已替换 |
| 原理组 | P14 | 6 个角编号 | 学生上台指完角后翻 | 叠化 | — |

**写法要求**：一页一行；"本页只新增什么"必须是一个可数元素（一个点/一条线/一个词/一行结论）。

## 5. 节奏与时长预算

- 每组 2–4 页；全课动画页占 35%–75%（原理/可视化密集型课可靠上限；超过 70% 时在 06 里写明理由）；16–24 页课件里约 6–10 组、14–18 页。
- 同类连续动画不超过 4 页，之后必须切回"整页综合"休息一下。
- 每页停留 20–90 秒：提问页可到 90 秒（含候答），结论页 20–30 秒。
- 全课翻页总次数控制在 30–45 次；超过说明页太碎。
- 计算：`页数 ≈ 教学时长(分) × 1.0–1.3`，其中 40% 给分步页。

## 6. 讲稿同步（最容易翻车的地方）

1. 备注里固定三行：`讲稿要点` / `教师动作` / `动画关系与翻页时机（停几秒、等什么信号）`。
2. 翻页时机绑定**学生行为**，不是绑定"我讲完了"：等学生说出关键词、等举手、等小组抬头。
3. 候答不足时，宁可在同一页停住，也不要提前翻页把答案亮出来。
4. 板书与屏幕同步：屏幕走到第 3 页时，黑板上必须落下对应的词。

## 7. 播放环境与备份

- 导出 PDF 备份（保留每页完整信息），U 盘与网盘各一份。
- 希沃/WPS 打开时先试翻一遍：检查字体替换、形状变形、遮罩色偏差。
- 字体：标题与正文各固定一种，避免在别人电脑上变成宋体/乱码；数学符号用文本+形状，不依赖特殊字体。
- 无动画也不影响：每页都能独立讲通，这是硬要求。

## 8. 常见错误对照表

| 错误 | 为什么不行 | 改法 |
|---|---|---|
| 一页塞满，靠转场营造"动画感" | 学生注意力被转场抢走，信息过载 | 拆成 2–4 页，每页一个信息点 |
| 复制同一页只多一行小字 | 变化太小看不见 | 新增元素放大 + 对比色 + 页脚序号 |
| 每页元素位置都变 | 学生找不到"变了什么" | 锁定坐标系，只动目标元素 |
| 自动播放动画 | 节奏不可控，提问等待被吞 | 全手动翻页，卡点写在备注 |
| 用动画代替板书 | 下课后黑板上没有"骨架" | 屏幕翻页 + 黑板同步落词 |
| 遮罩用半透明 | 投影仪显示成灰块，像没做完 | 遮罩色=背景色 |
| 导出 PDF 后信息丢失 | 学生课后看不懂 | 每页独立可读，导出后抽 2 页检查 |

## 9. 三步生成法（给模型的执行顺序）

1. **先写认知步骤**：这节课学生要经过哪几步（看见什么 → 做什么 → 说什么 → 得出什么），每步一句话。
2. **再映射到页**：一步一页或一步两页；标出每页的"新增元素"。
3. **最后写卡点**：每页写"学生出现什么信号就翻页"，并检查页数与时长预算。

> 生成 .pptx 时：形状绘制优先（可编辑、无版权问题）；同一序列用同一母版坐标；页脚写组名；备注写动画关系。生成后必须 python-pptx 重开校验页数/备注，并渲染 2–3 页目检无溢出。
